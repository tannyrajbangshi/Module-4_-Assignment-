MODULE 4 ASSIGNMENT - PROGRAMMING CODE
=====================================

A set of five simple JavaScript programs (Node.js).
Each program is in its own file and runs independently.


Requirements
------------

    Node.js v14 or later (https://nodejs.org)

No additional packages are needed.


How to Run
----------

    cd "Module-4_ Assignment_Programming_Code"
    node Task1.js

Replace Task1.js with Task2.js, Task3.js, Task4.js or Task5.js
to run the other programs.


Project Files
-------------

    Task1.js      Even or Odd Checker
    Task2.js      Largest of Three Numbers
    Task3.js      String Reversal
    Task4.js      Vowel Counter
    Task5.js      Remove Duplicates
    package.json  Project settings
    README.txt    This file


Task 1: Even or Odd Checker
---------------------------

Purpose : Checks whether a number is even or odd.

How it works:
Divides the number by 2 using the modulus operator (%). If the
remainder is 0, the number is even; otherwise, it is odd.

Output:

    25 is Odd


Task 2: Largest of Three Numbers
--------------------------------

Purpose : Finds the largest of three numbers.

How it works:
Compares each number with the other two using if / else if / else
and prints the largest one.

Output:

    Largest number is: 40


Task 3: String Reversal
-----------------------

Purpose : Reverses a given string.

How it works:
Splits the string into characters, reverses their order, and joins
them back together.

Output:

    Original String: Tanny rajbangshi
    Reversed String: ihsgnabjar ynnaT


Task 4: Vowel Counter
---------------------

Purpose : Counts the vowels (a, e, i, o, u) in a string.

How it works:
Converts the text to lowercase, loops through each character, and
increases a counter whenever a vowel is found.

Output:

    String: Tanny rajbangshi
    Number of vowels: 4


Task 5: Remove Duplicates
-------------------------

Purpose : Removes duplicate values from an array.

How it works:
Stores the array in a Set, which keeps only unique values, then
converts it back to an array.

Output:

    Original Array: [
      10, 20, 10, 30,
      20, 40, 30
    ]
    Array without duplicates: [ 10, 20, 30, 40 ]
